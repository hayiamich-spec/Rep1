# HF → GitHub Actions: загрузчик файлов датасетов (прототип)

Назначение: скачивать из Hugging Face Hub **публичные файлы датасетов** ZIP, TAR, Parquet, Arrow, CSV, JSON и прочие бинарные/текстовые форматы через GitHub Actions, управляя заданиями из чата посредством GitHub Issue. **Никакой код TAU/Aleph0 не изменяется.**

## Как развернуть
1. Поместить `.github/workflows/hf-import.yml` и `scripts/hf_import.py` в выделенный репозиторий GitHub (обычно в ветку `main`).
2. В настройках репозитория разрешить Actions. Для запуска из чата через Issues — включить Issues.
3. Создать через GitHub Issue заголовок `[HF-IMPORT] dataset-name` и тело JSON из `examples/request.json`. **Автор Issue должен быть владельцем репозитория.** Создание Issue запускает workflow, если файл workflow присутствует в ветке `main`.
4. Прочитать статус workflow и логи. По завершении скачать artifact ZIP (файл данных + `manifest.json` с SHA-256 и фиксацией commit исходного датасета).
5. Альтернативный запуск — кнопка Run workflow в интерфейсе GitHub (`workflow_dispatch`).

## Защитные ограничения
- Только `repo_type=dataset`, только идентификатор `owner/name`, только относительный путь файла, без прямых внешних URL.
- Максимум 250 MiB на файл (по умолчанию 100 MiB); до скачивания проверяется размер через HF API; неизвестный размер запрещает загрузку.
- Версия датасета закрепляется на точный SHA коммита.
- Ограничение runtime workflow — 15 минут; успешный artifact хранится 7 дней.
- **Репозиторий Rep1 публичный.** Workflow выполняет задания из Issues **только при создании владельцем**. Названия файлов, источники и доступные участникам артефакты могут быть публичными.
- Не скачивайте данные с ограниченной лицензией или персональные данные без проверки прав.

## Что пока не делает
- Не скачивает автоматически *все* файлы репозитория или очень крупные датасеты.
- Не распаковывает архивы, не выполняет подготовку временных рядов и не обучает TAU.
- Не передаёт ZIP напрямую в TAU. Для этого нужен отдельный штатный пакетный импорт либо небольшие порции через существующие методы TAU.

Это **изолированный прототип** для безопасного первого сквозного теста. Для больших наборов нужен облачный object storage и отдельное пакетное API.
